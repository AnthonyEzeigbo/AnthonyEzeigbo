## Hi there 👋 I'm Anthony Ezeigbo

# Cloud Engineer | DevOps

I'm a Cloud Enthusiast focused on AWS Cloud Engineering, with an interest in designing, building, and optimizing secure, scalable, and reliable cloud solutions. I enjoy turning cloud concepts into practical implementations, exploring infrastructure automation, and understanding how AWS services work together to solve real-world challenges.

My focus is on building hands-on experience with cloud infrastructure, Infrastructure as Code (IaC), automation, and DevOps practices. I work with technologies that support modern cloud environments, emphasizing reliability, security, efficiency, and continuous improvement.

My Technical Focus Areas

AWS Cloud Architecture: Working with Amazon EC2, Amazon S3, AWS IAM, Amazon VPC, AWS Lambda, and Amazon CloudWatch to build and understand cloud-based solutions.

Infrastructure as Code (IaC): Using Terraform to define, provision, and manage infrastructure through repeatable and consistent configurations.

Cloud Security: Applying security best practices, least-privilege access, identity management, and secure infrastructure design.

DevOps and Automation: Exploring Git, GitHub Actions, CI/CD pipelines, and automated deployment workflows to streamline infrastructure and application delivery.

Containers and Linux: Working with Linux, Docker, and Kubernetes to understand containerized applications and modern deployment environments.

Monitoring and Cost Optimization: Focusing on observability, troubleshooting, resource utilization, and responsible cloud spending.

I believe the best way to grow as an engineer is to build, test, troubleshoot, and continuously improve. I'm committed to developing practical solutions, documenting my work, and strengthening my ability to design and manage cloud infrastructure that meets real-world requirements.

I'm always open to connecting with AWS professionals, Cloud Engineers, DevOps practitioners, technology enthusiasts, and recruiters. I welcome opportunities to exchange ideas, collaborate on projects, expand my professional network, and explore opportunities in cloud engineering.

Let's connect! If you're a recruiter looking for cloud talent or a professional interested in AWS, cloud architecture, infrastructure automation, or DevOps, feel free to reach out via LinkedIn or email. I'm always open to meaningful conversations, collaboration, and new opportunities to grow and contribute.
